# Feature Specification: 字母練習排版與羅馬音補強

**Feature Branch**: `003-practice-romaji-layout`  
**Created**: 2026-03-28  
**Status**: Draft  
**Input**: User description: "針對字母練習頁新增羅馬音補全、長音規則表格化、外來語擴張系統化排版，並確保 375px 下可辨識且不出現橫向捲動。"

> 本規格以繁體中文（zh-TW）撰寫；Constitution 維持英文。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 用表格快速理解長音規則 (Priority: P1)

作為日文初學者，我要在字母練習頁用一致、可掃讀的表格查看長音規則與範例，讓我能更快看懂規則與對應單字，不必在不同卡片與文字段落之間來回比對。

**Why this priority**: 長音規則屬於基礎辨識知識，且目前版面分散，會直接影響初學者的閱讀速度與理解成本。

**Independent Test**: 進入 `/practice` 頁面後，只檢查長音規則區塊，即可確認是否已改為單一表格結構、規則列是否獨立、以及每個範例是否同時呈現假名、羅馬音與中文翻譯。

**Acceptance Scenarios**:

1. **Given** 使用者進入 `/practice` 頁面，**When** 查看長音規則區塊，**Then** 系統必須以單一表格呈現規則與範例，而非多張獨立卡片。
2. **Given** 使用者查看長音規則區塊，**When** 某一列是規則說明，**Then** 該列必須單獨占一整列，且不與單字範例混排。
3. **Given** 使用者查看長音規則範例列，**When** 系統顯示某個單字範例，**Then** 該列必須清楚呈現假名、羅馬音、中文翻譯三個欄位。
4. **Given** 使用者查看「あ段 + う 不一定屬於規則長音」說明，**When** 系統呈現該內容，**Then** 必須提供多個實際單字或單詞範例，並以假名、羅馬音、中文翻譯的同一格式顯示。

---

### User Story 2 - 補齊拗音與外來語擴張的羅馬音資訊 (Priority: P2)

作為日文初學者，我要在清音拗音、合拗音與外來語擴張區塊看到完整且一致的羅馬音，讓我在辨識假名組合時，可以同時建立發音對照。

**Why this priority**: 這些區塊已存在於學習流程中，但目前羅馬音資訊不完整，會造成學習斷點與不一致體驗。

**Independent Test**: 只檢查清音拗音、合拗音、外來語擴張三個區塊，即可驗證所有既有與新增的假名組合是否都有對應羅馬音，且外來語擴張是否已改為系統化矩陣。

**Acceptance Scenarios**:

1. **Given** 使用者查看清音拗音區塊， **When** 檢視任一非表頭儲存格， **Then** 該假名組合必須同時呈現假名與羅馬音。
2. **Given** 使用者查看合拗音區塊， **When** 檢視任一假名組合， **Then** 每個組合都必須顯示對應羅馬音。
3. **Given** 使用者查看外來語擴張區塊， **When** 檢視資料表， **Then** 第一列與第一欄必須作為基本音標頭，其餘儲存格以第一列與第一欄的組合邏輯呈現內容。
4. **Given** 外來語擴張區塊中出現僅有假名的內容， **When** 系統顯示該內容， **Then** 羅馬音必須顯示在假名下方，且兩者皆置中排列。

---

### User Story 3 - 在 375px 手機寬度下仍保持可讀與不破版 (Priority: P3)

作為主要使用手機學習的使用者，我要在 375px 寬度下仍能清楚閱讀練習頁的重要表格與共享 route tabs 區域，讓我不需要橫向捲動或放大縮小就能完成學習。

**Why this priority**: 本專案以手機使用情境為主要驗收尺寸，若 375px 下出現裁切、重疊或橫向捲動，會直接破壞學習流程。

**Independent Test**: 將畫面寬度設為 375px，檢查 `/practice` 共享 route tabs、長音規則表格、拗音表格與外來語擴張表格，即可驗證在不橫向捲動的前提下內容仍可辨識。

**Acceptance Scenarios**:

1. **Given** 使用者以 375px 寬度開啟 `/practice`， **When** 頁面初次渲染完成， **Then** 共享 route tabs 與主要內容區不得出現橫向捲動、裁切或重疊。
2. **Given** 使用者以 375px 寬度查看清音拗音、合拗音、外來語擴張與長音規則區塊， **When** 空間不足， **Then** 系統可先縮減儲存格內距，再視需要縮小字體，但不得以橫向捲動、裁切或重疊作為處理方式。
3. **Given** 使用者首次開啟 `/practice` 頁面， **When** 尚未展開任何互動內容， **Then** 頁面必須正常渲染，且不產生 runtime error、render failure 或 browser console error。

---

### Edge Cases

- 在 375px 寬度下，表格內容較長時，系統必須優先縮減內距與字級，仍不可出現橫向捲動、裁切或重疊。
- 只有假名、沒有既有羅馬音的資料列，仍必須補上羅馬音，且羅馬音需維持在假名下方。
- 外來語擴張矩陣中，第一列與第一欄作為基本音標頭時，不可被誤當成一般內容格處理。
- 長音規則表格中的說明列與範例列必須有明確區別，避免使用者把規則文字誤判為單字例子。
- 功能僅限於 `/practice` 頁面及其承載的共享 route tabs 佈局；`/grammar`、`/vocabulary`、測驗流程內容、PWA toast 與最近錯題面板均不在本 feature 的內容範圍內。
- 預設、空資料、隱藏或 placeholder 狀態下，頁面不得因新增排版或資料欄位而造成初始化錯誤。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系統 MUST 在 `/practice` 頁面將長音規則區塊改為單一表格式展示。
- **FR-002**: 系統 MUST 讓長音規則中的規則說明列獨立占用整列，不得與範例列混排。
- **FR-003**: 系統 MUST 讓長音規則的單字或單詞範例以「假名／羅馬音／中文翻譯」三欄展示。
- **FR-004**: 系統 MUST 將「あ段 + う 不一定屬於規則長音」由純說明改為多個範例列，並沿用同一三欄格式。
- **FR-005**: 系統 MUST 在清音拗音區塊中，為每個非表頭的假名組合補上對應羅馬音。
- **FR-006**: 系統 MUST 在合拗音區塊中，為每個假名組合補上對應羅馬音。
- **FR-007**: 系統 MUST 將外來語擴張區塊整理為系統化矩陣，第一列與第一欄必須作為基本音標頭。
- **FR-008**: 系統 MUST 讓外來語擴張矩陣中的內容格依第一列與第一欄的排列組合邏輯呈現。
- **FR-009**: 系統 MUST 在所有只有假名的展示內容中補上羅馬音。
- **FR-010**: 系統 MUST 讓「假名在上、羅馬音在下」成為外來語擴張內容格的標準呈現方式，且文字需水平與垂直置中。
- **FR-011**: 系統 MUST 讓假名內容維持可辨識且不因換行規則而破壞主要讀取方式。
- **FR-012**: 系統 MUST 將本 feature 的展示範圍限制在 `/practice` 頁面、其內的長音規則、清音拗音、合拗音、外來語擴張區塊，以及支撐該頁閱讀性的共享 route tabs 排版。
- **FR-013**: 系統 MUST 明確保持 `/grammar`、`/vocabulary`、測驗 modal、錯題面板、PWA toast 等其他表面不新增本 feature 的展示內容。
- **FR-014**: 系統 MUST 在 375px 寬度下保持 `/practice` 共享 route tabs 區與本 feature 涉及的表格區塊可辨識，且不得出現橫向捲動、裁切或重疊。
- **FR-015**: 當 375px 寬度下空間不足時，系統 MUST 先縮減表格儲存格內距，再視需要縮小字體；不得以橫向捲動作為處理方式。
- **FR-016**: 系統 MUST 在預設、空資料、隱藏與 placeholder 狀態下維持 render-safe 行為，不得因本 feature 造成 runtime error、render failure 或 browser console error。
- **FR-017**: 系統 MUST 讓新舊羅馬音命名與展示用語在相關區塊內保持一致，避免同一概念出現多組不一致標示。

### Key Entities *(include if feature involves data)*

- **展示範例列**: 用於呈現規則說明、單字範例或假名組合的可視資料單位，可能包含標題、假名、羅馬音、中文翻譯與版型角色。
- **外來語擴張矩陣**: 由基本音標頭與內容格組成的展示結構，用於表達第一列與第一欄的組合關係。
- **共享頁首佈局**: `/practice` 頁面進入時可見的共享 route tabs 區，需滿足 375px 可讀性要求，且按鈕文字不得斷行。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 在 375px 寬度下，使用者進入 `/practice` 後可於 10 秒內辨識出長音規則區塊中的規則列與範例列差異。
- **SC-002**: 100% 的清音拗音、合拗音與本次外來語擴張內容格都能直接看到對應羅馬音，無需額外切換或互動。
- **SC-003**: 在 375px 主要驗收尺寸下，`/practice` 共享 route tabs 區與本 feature 涉及的表格區塊皆不出現橫向捲動、裁切或重疊。
- **SC-004**: `/practice` 頁面在預設初始渲染時維持可用，且針對本 feature 涉及的區塊不產生 runtime error、render failure 或 browser console error。

## Assumptions

- 使用者的主要學習流程仍以 `/practice` 為主，本 feature 不改變既有測驗流程與錯題儲存邏輯。
- 若既有資料結構不足以表達假名、羅馬音與中文翻譯的三欄關係，可調整展示資料結構，但不改變學習內容的核心分類名稱。
- 375px 為主要驗收尺寸；768px 與 1024px 只要求不破版與保持可辨識，不要求與手機版完全相同的視覺密度。

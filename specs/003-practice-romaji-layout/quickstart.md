# Quickstart: 字母練習排版與羅馬音補強

## 1. 安裝與啟動

```bash
npm ci
npm run dev
```

## 2. 主要驗證流程

### 流程 A：長音規則大表格

1. 進入 `/practice`。
2. 找到長音規則區塊，確認它不是多張卡片，而是一張完整表格。
3. 確認每個規則說明列獨占整列。
4. 確認每個範例列都可同時看到假名、羅馬音、中文翻譯。
5. 特別檢查「あ段 + う 不一定屬於規則長音」，確認它已改成多個範例列，不是純文字說明。

### 流程 B：拗音與合拗音羅馬音補全

1. 在 `/practice` 找到清音拗音區塊。
2. 抽查任一非表頭格，確認假名與羅馬音同時可見。
3. 找到合拗音區塊，抽查數個格位，確認每格都有羅馬音。
4. 確認補上的羅馬音命名在同一區塊內一致。

### 流程 C：外來語擴張矩陣

1. 在 `/practice` 找到外來語擴張區塊。
2. 確認第一列與第一欄為基本音標頭。
3. 確認其餘內容格是第一列與第一欄的組合結果。
4. 抽查數個只有假名的內容格，確認版型為「假名在上、羅馬音在下」且置中。

### 流程 D：375px 響應式驗證

1. 將 viewport 設為 `375px`。
2. 確認共享 route tabs 與路由切換按鈕仍可辨識，且沒有橫向捲動。
3. 檢查長音規則、清音拗音、合拗音、外來語擴張區塊：
   - 不得裁切。
   - 不得重疊。
   - 不得使用橫向捲動解決版面問題。
4. 若內容變緊密，確認呈現方式是先縮減內距，再視需要縮小字體。

### 流程 E：render-safe 與既有功能未回歸

1. 重新整理 `/practice`，不進行任何操作。
2. 確認頁面正常渲染，沒有 console error。
3. 確認 `ExamModal`、最近錯題面板、PWA toast 行為沒有因本 feature 額外出現新內容。

## 3. 建議驗證指令

```bash
npm run lint
npm run typecheck
npm run test:unit
npm run build
```

## 4. 若需要手動檢查 PWA 相容性

1. 執行 `npm run build`。
2. 以既有 PWA 流程開啟站點。
3. 在離線狀態重新開啟 `/practice`，確認本次新增的靜態教學資料仍可顯示。

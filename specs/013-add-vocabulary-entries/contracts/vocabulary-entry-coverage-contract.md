# 契約：`/vocabulary` 指定詞義覆蓋與字典追加

## 路由範圍

- 功能介面: `/vocabulary`
- 不得改動:
  - `/practice`
  - `/grammar`
  - `/n5-grammar`
  - 共享路由頁籤
  - 應用程式外框

## 覆蓋保證

| 指定詞義 | 預期日文詞條 | 來源 | 規則 |
|----------|--------------|------|------|
| `皮膚` | `肌` | 新增詞條 | 必須新增 |
| `光滑` | `滑らか` | 新增詞條 | 必須新增 |
| `動作` | `動き` | 新增詞條 | 必須新增；不得以 `動く` 代替 |
| `說話` | `話す` | 既有詞條 | 不得重複新增 |

## 資料保證

- `rawVocabularyEntries` 長度由 `1076` 變為 `1079`。
- 新增資料必須只出現在 `rawVocabularyEntries` 尾端。
- 新增資料尾端順序固定為：
  1. `肌`
  2. `滑らか`
  3. `動き`
- 既有 1..1076 筆資料順序不得改動。
- 既有 `話す -> 說話` 覆蓋必須保留。

## 介面保證

- `/vocabulary` 預設載入 count summary 必須顯示 `1079個單字`。
- 使用者可透過既有搜尋流程，用中文詞義找到本次新增或既有覆蓋的詞條。
- 本次變更不得破壞既有註記、長按揭露、欄位切換與 marked-only 行為。

## 負向保證

- 本功能不得新增新的 `/vocabulary` 專屬 UI 區塊。
- 本功能不得引入新的路由、共享 composable、共享元件或部署變更。
- 本功能不得要求更新 `PROJECT_ARCHITECTURE.md`，除非實作意外擴大到結構調整。

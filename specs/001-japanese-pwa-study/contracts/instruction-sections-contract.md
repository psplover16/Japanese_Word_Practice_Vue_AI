# Contract: 教學區塊內容範圍

## 必備區塊

- `table撥音`
- `table促音`
- `table清音拗音`
- `table合拗音`
- `table外來語擴張`
- `長音規則`
- `特殊音節`

## 驗收邊界

- 每個區塊皆獨立元件與獨立容器。
- `table撥音`、`table促音` 使用內容撐寬表。
- 拗音類表格使用固定格表。
- 長音規則使用標題 + 多個 rule card，而非強制 table。

## Shared Style Boundary

- 不得因重用方便，把所有教學區塊都強制套進同一套表格樣式。
- 若某區塊有明確 layout 規則，該規則優先於 reusable abstraction。

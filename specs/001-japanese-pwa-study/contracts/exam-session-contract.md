# Contract: 考試 Modal 與結算流程

## 開始考試前置條件

- `[題數] >= 1`
- 至少勾選一個 `tableA` 或 `tableB` 假名
- `題目包含：平假名`、`題目包含：片假名` 至少有一個為 `true`

## Modal 結構

- 全頁遮罩，需阻擋背景互動。
- 中央固定尺寸卡片：
  - 上方：進度與關閉按鈕
  - 中間：題目、答案、提示
  - 下方：`下一步`、`我不清楚`

## Flow

- `下一步`
  - 答案未揭曉：先顯示答案
  - 答案已揭曉：進入下一題
- `我不清楚`
  - 本題只記錄一次
  - 仍然依當前揭曉狀態推進到下一步
- `關閉`
  - 先顯示原生確認警告
  - 取消：保持目前考試狀態
  - 確認：立即結算並關閉 modal

## Settlement

- 寫入固定 localStorage key
- 覆蓋舊結果
- 更新第一頁下方結算區
- 若有結果，結算後畫面 smooth scroll 到結果區

# Feature Specification: 日語學習 PWA

**Feature Branch**: `001-japanese-pwa-study`  
**Created**: 2026-03-23  
**Status**: Draft  
**Input**: User description: "以 PWA 形式提供可離線的日語字母練習、變化規則、單字練習三個路由，並依 private 規格完成表格、共享勾選狀態、考試 modal、結果結算與更新提示。"

> 本規格以繁體中文（zh-TW）撰寫，並以使用者可見行為、驗收條件與資料範圍為主。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 字母練習與考試流程 (Priority: P1)

作為想要練習日語假名的使用者，我想在「字母練習」路由勾選想考的清音、濁音／半濁音與功能選項，並直接在同一路由開始考試、查看最近一次結算結果，這樣我可以快速完成一輪練習。

**Why this priority**: 這是產品的核心價值，也是其他路由共享狀態與教學說明的來源。

**Independent Test**: 只實作此故事時，使用者仍可在第一頁完成勾選、出題、關閉考試、結算、清除結果與重新進入頁面的完整流程。

**Acceptance Scenarios**:

1. **Given** 使用者剛進入字母練習頁面，**When** 勾選 tableA / tableB 的假名與題目範圍，**Then** 題數會依目前勾選結果自動計算，且切換路由後回來仍保留同一份勾選狀態。
2. **Given** 使用者按下送出開始考試，**When** 題數、勾選假名與題目範圍都有效，**Then** 系統會以 modal 顯示固定尺寸的考試卡片，並依題目範圍與勾選的假名隨機出題。
3. **Given** 使用者在考試中按下「我不清楚」或於答案揭曉前後標記同一題，**When** 該題結算，**Then** 該題只會記錄一次，並在最近一次結算結果中累加到對應假名。
4. **Given** 使用者在考試中按下右上角關閉按鈕並確認結束，**When** modal 關閉，**Then** 系統必須立即執行與正常完成相同的結算流程，覆蓋寫入固定 localStorage，並更新頁面下方結算區域。

---

### User Story 2 - 跨路由閱讀共享勾選明細 (Priority: P2)

作為正在切換到「變化規則」或「單字練習」路由的使用者，我希望可以直接看到第一頁已勾選的假名與功能選項的實際文字，這樣我能在不回第一頁的情況下確認目前正在練習哪些內容。

**Why this priority**: 第二頁與第三頁目前功能尚少，但已被要求先實作共享狀態的唯讀明細，這是後續擴充的基礎。

**Independent Test**: 在第一頁勾選任意假名與功能選項後，第二頁與第三頁都能顯示完整文字明細，而第一頁不會額外顯示同樣的明細區。

**Acceptance Scenarios**:

1. **Given** 第一頁已勾選 tableA 的假名、tableB 的假名與 checkboxGroupA 的功能選項，**When** 使用者切換到第二頁或第三頁，**Then** 畫面必須顯示所有已勾選項目的實際文字，而不是只顯示數量、摘要或布林值。
2. **Given** 使用者回到第一頁，**When** 查看字母練習路由，**Then** 第一頁不得出現「第一頁勾選結果明細」專屬區塊，第一頁只作為共享狀態來源。

---

### User Story 3 - 可離線使用且可更新的 PWA 體驗 (Priority: P3)

作為會把網站安裝到手機上的使用者，我希望這個網站能在離線時使用，且當有新版本時在符合條件的情境下得到更新提示，這樣我可以持續用最新內容練習又不必依賴網路。

**Why this priority**: PWA 與離線能力是整體產品目標的一部分，但不影響第一頁核心練習流程先成立。

**Independent Test**: 網站可安裝為 PWA，離線仍能開啟已建置內容；當有新版本且以手機獨立 app 模式執行時，畫面底部會顯示更新提示，並在更新完成後清除 Cache Storage 而不影響其他 localStorage。

**Acceptance Scenarios**:

1. **Given** 使用者已安裝網站為 PWA，**When** 裝置暫時離線，**Then** 仍可開啟網站並進入三個主要路由。
2. **Given** PWA 有可套用的新版本，**When** 使用者以手機獨立 app 模式開啟網站，**Then** 會在畫面底部看到更新提示，5 秒後提示消失；若本次不更新，則下次重開網站時自動更新。

## Clarifications

### Session 2026-03-23

- Q: 各路由標題為何？ → A: `字母練習` 路由標題為 `50音`，`變化規則` 路由標題為 `變化規則`，`單字練習` 路由標題為 `單字練習`。
- Q: PWA 更新提示何時顯示？ → A: 只在手機端且以獨立 app 模式執行時顯示，固定懸浮於畫面底部，距離底部約 16px。
- Q: 提示消失後的更新策略為何？ → A: 當次不更新，但下次重新開啟網站時自動更新；更新完成後要清除與更新相關的儲存空間，但不能動到其他功能的 localStorage。
- Q: `tableA` 與 `tableB` 在 375px 驗收寬度下如何處理？ → A: 兩者都不得出現滾動條、破版、裁切或重疊，且內容必須仍可正常辨識。
- Q: 被勾選的 checkbox 是否需要視覺回饋？ → A: 需要，checkbox 所在的 td 被勾選時要變色，取消勾選後恢復。
- Q: `古語假名` checkbox 的位置在哪裡？ → A: 位於 `checkboxGroupA` 內部，且在按鈕 Group 正上方，不能出現在 `tableA` 下方、`tableB` 下方或 `checkboxGroupA` 之外。
- Q: `table撥音` 與 `table促音` 能否沿用固定欄寬表格樣式？ → A: 不可以。左側欄位由內容撐出寬度，不得使用固定欄寬。

## Edge Cases

- 使用者未勾選任何 tableA / tableB 假名時按下送出，系統必須以警告阻止出題。
- 使用者把 `題目包含：平假名` 與 `題目包含：片假名` 都取消勾選時按下送出，系統必須以警告阻止出題。
- `[題數]` 為 `0`、空字串或非有效正整數時按下送出，系統必須以提示阻止出題。
- `古語假名` 預設隱藏時，對應儲存格仍必須保留位置並顯示 `-`，不得因 hidden / placeholder 狀態造成 runtime error、render failure 或 browser console error。
- 在 375px 驗收寬度下，`tableA` 與 `tableB` 都不得出現水平或垂直滾動條，也不得破版、裁切或重疊。
- `table撥音`、`table促音` 的左欄寬度由內容撐起，若文字過長可有意義換行，但不得為了共用樣式而變成固定欄寬。
- 第一頁只作為共享狀態來源，不得額外顯示「第一頁勾選結果明細」區塊；第二頁與第三頁才顯示該明細。
- 關閉 modal 時若按下取消，題目進度與已標記的「我不清楚」內容都必須保持不變。
- localStorage 中最近一次結算資料若格式無法解析，系統必須自動清除該資料，避免渲染錯誤。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系統必須提供三個主要路由：`字母練習`、`變化規則`、`單字練習`，並在最外層固定容器中顯示當前路由標題與路由切換按鈕 group。
- **FR-002**: 最外層固定容器的 `padding-y` 必須為 `12px`，`padding-x` 必須為 `8px`，在 `375px` 驗收寬度下不得出現橫向捲動、破版、裁切或重疊。
- **FR-003**: 第一頁任何勾選狀態在切換路由後都必須保留，其他路由只能唯讀這些狀態，不得直接寫入。
- **FR-004**: 重新整理或重啟網站後，第一頁勾選狀態必須回復為預設值，不跨重新整理保存。
- **FR-005**: `tableA` 必須顯示清音假名，包含水平與垂直標頭，並以五段十行分類方式排列；標頭文字不得斷行。
- **FR-006**: `tableA` 除標頭外的每個儲存格必須由上至下顯示 checkbox、平假名／片假名、羅馬拼音，且平假名／片假名不得斷行。
- **FR-007**: `tableA` 的標頭與內容儲存格都必須支援整個 td 點擊勾選／取消勾選；勾選標頭時必須影響對應整行或整列的假名。
- **FR-008**: `tableB` 必須顯示寬 5 格、高 5 格的濁音／半濁音表格，且每個儲存格的內容與勾選功能規則與 `tableA` 非標頭儲存格一致。
- **FR-009**: `tableA` 與 `tableB` 的每一個儲存格都必須水平置中、垂直置中；被勾選的 checkbox 所在 td 必須變色，取消勾選後恢復。
- **FR-010**: `tableA` 與 `tableB` 在 `375px` 驗收寬度下都不得出現滾動條、破版、裁切或重疊，且內容必須仍可正常辨識。
- **FR-011**: `tableA` 中的古語假名預設為隱藏且不可勾選；當 `古語假名` checkbox 未勾選時，對應位置必須顯示 `-` 並保留固定格位。
- **FR-012**: `checkboxGroupA` 必須控制 `tableA`、`tableB` 與考試功能區，且除特別說明外所有 checkbox 預設為未勾選；只有 `題目包含：平假名` 與 `題目包含：片假名` 預設為已勾選。
- **FR-013**: `checkboxGroupA` 必須包含 `題目包含：平假名`、`題目包含：片假名`、`全選／全不選`、`濁音／半濁音`、`促音`、`拗音／合拗音／長音符`、`古語假名`、`題數` input，以及 `送出`、`重置`、`清除結果` 三個按鈕。
- **FR-014**: `全選／全不選` 勾選時必須同時勾選 `tableA`、`tableB` 與 `tableA` 標頭的可勾選項目；任一對應項目被取消勾選時，`全選／全不選` 只能反映未全選狀態，不得反向觸發其他項目。
- **FR-015**: `濁音／半濁音` checkbox 勾選時必須同時勾選 `tableB` 所有可勾選項目；任一 `tableB` 項目被取消勾選時，該 checkbox 只能反映未全選狀態，不得反向觸發其他項目。
- **FR-016**: `古語假名` checkbox 只負責顯示／隱藏古語假名，不得進入出題、統計或全選邏輯。
- **FR-017**: `checkboxGroupA` 的版面由上到下必須固定為四個主要區塊：功能 checkbox 區、題數 input 區、`促音`／`拗音／合拗音／長音符` 區、`古語假名` 與按鈕 Group 區，其中 `古語假名` 必須位於按鈕 Group 正上方。
- **FR-018**: `[題數]` input 只能輸入數字，且必須依 `tableA`、`tableB` 勾選數量與 `題目包含：平假名`、`題目包含：片假名` 的勾選結果自動重新計算。
- **FR-019**: 使用者可手動修改 `[題數]`，但下一次假名勾選或題目範圍變更時，系統必須以最新重新計算值覆蓋。
- **FR-020**: `重置` 必須取消所有 checkbox 包含 `古語假名`，但 `題目包含：平假名` 與 `題目包含：片假名` 在重置後必須保持勾選。
- **FR-021**: `清除結果` 按下後必須先跳出原生確認警告，確認後完全刪除最近一次測驗結算資料。
- **FR-022**: `table撥音` 與 `table促音` 都必須顯示一條單句標題與一個兩欄表格，左欄由內容撐起寬度，不得設置固定寬度或被共用樣式改成固定欄寬。
- **FR-023**: `table清音拗音`、`table合拗音`、`table外來語擴張`、`長音規則`、`特殊音節` 都必須獨立製作與驗收，且視覺上屬於字母練習頁面的教學區塊。
- **FR-024**: `送出` 開始考試前，系統必須依序驗證 `[題數] >= 1`、至少勾選一個 tableA / tableB 假名、以及至少勾選 `題目包含：平假名` 或 `題目包含：片假名` 其中之一。
- **FR-025**: 驗證通過後，系統必須以 modal 顯示固定尺寸的考試卡片，遮罩需覆蓋全頁並阻止背景互動。
- **FR-026**: 考試題目必須來自 `tableA` 與 `tableB` 已勾選的假名，依 `[題數]` 決定題目總數，在題數允許下盡量讓每個勾選假名都出現，且順序需隨機。
- **FR-027**: 若只勾選 `題目包含：平假名`，則只考平假名；若只勾選 `題目包含：片假名`，則只考片假名；若兩者都勾選，則兩者都要考。
- **FR-028**: 考試卡片上方必須顯示 `目前題數 / 總共題數` 與右上角關閉按鈕，中間題目區固定分為 `題目`、`答案`、`提示` 三個由上到下排列的區塊，按鈕區塊固定於底部。
- **FR-029**: 題目區必須先顯示假名，答案揭曉前不得顯示羅馬拼音；答案區在隱藏時仍須保留固定高度，避免版面位移。
- **FR-030**: `下一步` 在答案揭曉前必須先顯示答案，答案揭曉後再進入下一題；題目都出完後，按下 `下一步` 必須關閉 modal 並進行結算。
- **FR-031**: `我不清楚` 無論在答案揭曉前或後都必須記錄目前題目的假名，但同一題只記錄一次，且流程仍需與 `下一步` 一樣推進。
- **FR-032**: 右上角關閉按鈕按下後必須跳出原生確認警告；取消則回到考試狀態，確認則視為立即結束並執行與正常完成相同的結算流程。
- **FR-033**: 結算必須將本次按下 `我不清楚` 的假名統計為最近一次結果，覆蓋寫入固定 localStorage，跨重新整理與重開網站保留，直到下一次測驗覆蓋或使用者按下 `清除結果`。
- **FR-034**: 結算區域必須顯示在第一頁最下方，標題為 `我不清楚的音節`，並以 tag 呈現 `平假名／片假名 羅馬音` 與次數；當沒有任何結果時不得顯示該區域。
- **FR-035**: 進入第一頁或關閉考試 modal 完成結算時，若有最近一次結果，畫面必須 smooth scroll 到結算區域。
- **FR-036**: 第二頁與第三頁都必須先實作 `第一頁勾選結果明細顯示區`，其資料來源必須同時包含 tableA、tableB 與 checkboxGroupA 的勾選內容。
- **FR-037**: 第二頁與第三頁顯示的明細必須是使用者可閱讀的實際文字，不可只輸出 id、key、布林值、勾選數量或摘要。
- **FR-038**: 第一頁不得顯示 `第一頁勾選結果明細` 區塊；此功能只允許出現在第二頁與第三頁。
- **FR-039**: 第二頁與第三頁目前尚未有完整詳細內容時，仍必須保留各自的 route 標題、共享明細區與後續可擴充的內容容器。
- **FR-040**: 系統必須支援 PWA 安裝與完全離線模式，並使用指定的 public icons 與網站 icon。
- **FR-041**: 當 PWA 偵測到新版本時，只有在手機端且以獨立 app 模式執行才可顯示更新提示；提示固定於畫面下方，約 5 秒後消失。
- **FR-042**: 使用者在提示存在期間按下確認更新時，系統必須更新並重新載入；若本次未更新，則下次重新開啟網站時必須自動更新。
- **FR-043**: 更新完成後，系統必須清除與 PWA 更新相關的 Cache Storage，但不得清除其他功能使用的 localStorage。

### Key Entities *(include if feature involves data)*

- **KanaCell**: 代表 tableA 或 tableB 中一個可練習的假名單位，包含所屬 table、羅馬拼音、平假名、片假名，以及是否屬於古語假名。
- **SelectionState**: 代表第一頁所有勾選狀態，包含 tableA / tableB 已勾選假名、題目範圍 checkbox、特殊音節 checkbox、古語假名顯示狀態與目前題數。
- **ExamQuestionCard**: 代表 modal 內的一題，包含題目文字、答案文字、提示文字、對應假名識別與本題是否已記錄 `我不清楚`。
- **LatestUnknownResult**: 代表最近一次結算結果，包含假名文字、羅馬拼音、累積次數與更新時間。
- **PwaUpdateNotice**: 代表 PWA 新版本可用時的畫面提示，包含顯示條件、剩餘時間與是否需要立即更新。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 使用者在第一頁勾選任意假名與題目範圍後，切換到第二頁或第三頁時，100% 都能看到對應的實際文字明細，且第一頁不會顯示該明細區。
- **SC-002**: 在 `375px` 驗收寬度下，`tableA` 與 `tableB` 都不得出現滾動條、裁切、重疊或破版，且主要文字仍可清楚辨識。
- **SC-003**: 使用者在考試進行中按下關閉並確認結束後，最近一次結算結果必須立即出現在第一頁下方並覆蓋 localStorage 內舊資料。
- **SC-004**: 當 localStorage 內最近一次結算資料合法時，重新整理或重開網站後仍能在第一頁看到同一份結算結果；當資料非法時，網站不會產生 render error，且該資料會被清除。
- **SC-005**: 安裝為 PWA 後，使用者在無網路情境下仍可開啟三個主要路由；有新版本時，只有在手機獨立 app 模式下會看到更新提示。

## Repository Hygiene *(mandatory)*

- 實作前必須確認 repository 已包含 `.gitignore`。
- 不得提交 `node_modules/`。
- 不得提交 `build/`、`dist/`、`coverage/` 等可重新生成的產物，除非有明確規格例外。

# Quickstart：日語學習 PWA

## 1. 安裝依賴

```bash
npm install
```

## 2. 啟動開發環境

```bash
npm run dev
```

開啟瀏覽器後確認：

- 預設可進入三個主要頁面之一，並可快速切換到另外兩頁
- 最外層容器為 `py-[12px] px-2`
- 頁首左側顯示目前路由標題，右側顯示路由切換按鈕群
- `/practice` 顯示 `50音`，`/grammar` 顯示 `變化規則`，`/vocabulary` 顯示 `單字練習`
- 頁首標題與路由切換按鈕群在同一列時不得斷行

## 3. 核心手動驗證

### 字母練習與共享狀態

- 勾選清音與濁音後切換到其他頁，再切回第一頁，確認勾選狀態仍在
- 重新整理頁面後確認勾選回到預設
- 第二頁與第三頁可以看到共享勾選資訊，但不能修改

### 工具列與確認流程

- 題數為 `0` 時按送出，確認會阻擋並顯示提示
- 按下「清除結果」後確認會先跳出確認提示
- 在清除結果確認提示中按取消，確認結果仍保留
- 在測驗 modal 中按關閉按鈕，確認會先跳出「確定要結束練習嗎？」

### 測驗流程

- 勾選至少一個字母後開始測驗，確認 modal 依序支援揭曉答案與下一題
- 同題在答案揭曉前後都按「我不清楚」，確認只累計一次
- 在未完成測驗時按關閉並確認，確認不會覆蓋既有最近一次測驗結果
- 測驗正常完成後，確認結果寫入 `localStorage` 並顯示於結算區

### 教學區塊獨立驗收

- 分別檢查以下區塊是否可單獨顯示與驗收：
  - 古語假名開關
  - 撥音
  - 促音
  - 清音拗音
  - 合拗音
  - 外來語擴張
  - 長音規則
  - 特殊音節
- 關閉古語假名開關時，確認不影響題數與出題範圍

### 結算區與壞資料防呆

- 手動把 `duotify.exam.latestUnknownResults` 改成錯誤 JSON
- 重新整理後確認頁面不會崩潰，且錯誤資料會被清掉

## 4. PWA 驗證

### 建置

```bash
npm run build
npm run preview
```

### 離線

- 先在線上成功載入一次
- 在 DevTools 切換為 Offline
- 重新開啟應用，確認三個頁面、測驗流程與靜態內容仍可使用
- 確認首次可離線使用時會看到提示

### 更新

- 模擬 service worker 新版可用
- 確認提示只顯示 5 秒
- 5 秒內確認更新時，應立即重新載入
- 若未確認，重新關閉並開啟應用後應自動套用新版
- 更新後確認舊 Cache Storage 已被清理，`localStorage` 仍保留

## 5. 效能驗證

- 在主要內容已載入完成後，量測三個主要頁面間切換，確認 `1 秒` 內可互動
- 在測驗 modal 中量測按下「下一步」後的揭曉或換題更新，確認 `0.2 秒` 內完成
- 執行 Lighthouse，記錄首頁與字母練習頁的互動品質結果

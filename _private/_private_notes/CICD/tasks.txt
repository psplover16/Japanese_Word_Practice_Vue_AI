# Tasks: 導入 unit test + e2e + GitHub Actions CI/CD

## Task Group 1: Unit Test Foundation
1. 確認目前專案技術棧與測試相容性
2. 安裝並設定 unit test 框架
3. 新增 package scripts 以支援本地與 CI 執行 unit test
4. 建立最小可運作的 unit test 設定檔
5. 建立測試檔目錄規範
6. 為至少 3 個核心純邏輯模組補上 unit test
7. 驗證測試可於本地成功執行

## Task Group 2: E2E Foundation
8. 安裝並設定 Playwright
9. 建立 e2e 測試目錄與設定檔
10. 新增 package scripts 以支援本地與 CI 執行 e2e
11. 建立 1 條 smoke test（首頁或主要入口頁）
12. 建立 1 條核心主流程 e2e
13. 驗證 e2e 可於本地成功執行

## Task Group 3: CI Pipeline
14. 建立 `.github/workflows/ci.yml`
15. 設定 pull_request 觸發條件
16. 設定 push 觸發條件
17. 於 CI 中執行 dependency install
18. 於 CI 中執行 lint
19. 於 CI 中執行 unit test
20. 於 CI 中執行 build
21. 於 CI 中執行 e2e
22. 若 e2e 失敗，保留測試報告或 artifact 供排查
23. 驗證 CI 失敗時 workflow 狀態正確失敗

## Task Group 4: CD Pipeline
24. 建立 staging deploy workflow
25. 建立 production deploy workflow
26. 設定 dev 分支部署到 staging
27. 設定 main 分支部署到 production
28. 補齊所需 secrets / environment variables 使用說明
29. 若 production 有風險，加入 environment protection 或 manual approval
30. 驗證部署流程可在正確事件觸發

## Task Group 5: Documentation
31. 更新 README，補 unit test 執行方式
32. 更新 README，補 e2e 執行方式
33. 更新 README，補 CI / CD 觸發規則
34. 補充常見失敗排查方式
35. 補充後續新增測試的規範

Please create the implementation plan based on the following technical constraints and project rules.

Project type:
- This is a pure frontend web application with no backend service.
- The app should be built with Vue 3 + TypeScript + Vite + Tailwind CSS.
- SCSS may be used only when necessary.
- Use Composition API and avoid Options API.

Storage and data:
- Client-side persistence should use localStorage.
- Fixed/static content may be extracted into external JSON files.

Paths and assets:
- Use @ as the project root alias.
- Prefer relative-path based project organization.
- The project must support PWA.
- Use images under @/_private/_private_fileAssets/public/icons for PWA-required icons/images.
- The website icon may reference @/_private/_private_fileAssets/public/vite.ico.

Coding rules:
- Avoid var; use let or const instead.
- Avoid global variables; prefer local scope.
- Avoid global functions; prefer local/module-scoped functions.
- Avoid unnecessary third-party packages; prefer native/browser/platform capabilities when feasible.
- Do not use any; all types must be explicitly defined.
- Keep code concise and avoid duplicated logic.
- End statements with semicolons.
- Avoid ESLint errors.

Naming conventions:
- Component files must use PascalCase, for example: UserCard.vue, LoginForm.vue.
- Component names must be semantic and avoid meaningless abbreviations.
- Modular files should use camelCase, for example: userService.ts, authUtils.ts.

Repository hygiene:
- Design a proper .gitignore for files not needed by the project.

- 支援手機、平板、桌機。
- 設定主要斷點：<768px、768~1023px、>=1024px。

- 768px、1024px 為次要驗收尺寸，以不破版為原則，其餘彈性較高。

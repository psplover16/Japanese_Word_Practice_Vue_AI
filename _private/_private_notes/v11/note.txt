ch2. 助詞 も與其他的助詞
も　助詞，表示也。
以下是其他助詞與 も 使用上的分類
一. 原本助詞必定消失，被 も 替換 (必省略)
主題は，高橋さんは学生です。山田さんも学生です。
焦點が，寿司が好きです。ラーメンも好き（すき）です。
が，主語，或 跟狀態/感覺/能力 一起用，句子中間的 が 很常等於「但是、可是」，語氣比 でも 更柔和。 
二. 原本助詞幾乎會被替換 (極少部分不會被省略)
動作作用對象を，新聞（しんぶん）を買いました（かいました）。 雑誌（ざっし）も買いました。
1. 買う(詞幹) >> 買います(ます形) >> 買いました（過去敬語）
2. を，表示"動作"的「對象」，名詞 + を + 動詞
三. 很常省略
移動方向へ，京都（きょうと）へ行きました（いきました）。奈良（なら）へも　行きました。
1. 行く(原形) >> 行きます(ます形) >> 行きました (過去形)
2. へ 表示「方向」，朝某個方向移動，強調方向
3. 第二句的 へ，可省略，因為有 も
四. 不可省略
動作主題に，母に　プレゼント を あげました。父にもあげました。
1. 我送給媽媽禮物，也送給爸爸禮物。
2. プレゼント 表示禮物
3. 此處的 に，表示接受動作的人
3. を 受詞助詞，表示動作的對象。名詞都要用助詞標示語法腳色
4. あげる >>> 一段動詞
動詞 誰給誰
あげる 我給別人
くれる 別人給我
もらう 我收到で
5. 私は父にもあげました。 此句私は 可以省略主語
因為 あげる 具有方向性，可以清晰知道主語，所以主語可以省略
--
交通工具で，電車（でんしゃ）で 行く（いく）こと が できます。バスでも行くことができます。
1. 可以搭電車去，也可以搭巴士去。
1. で 助詞，用 ~~手段 / 方法 
3. 行く，表示 去。 こと 把動詞變成事情或動作的概念 (動詞變成名詞)
4. が，主語標記。 行くこと 是主語
5. できる ，一段動詞，表示 "能夠"。前面要接名詞。 
但此處是用敬體的變化
形式 意思
できます 可以
できません 不可以
できました 可以了

ch8.い形容詞過去肯定與否定 (かったです/くなかったです)
過去事項
うなぎ（鰻魚）は昔（むかし）、とても安（やす）かったです.　(鰻魚以前，非常便宜)
過去感想
昨日､うなぎを食べました。とてもおいしかったです。
-
平時都可以，但變化都是 よいです 去變化
いいです/よいです　＞＞　よかったです(過去肯定) >> よくないです(現在否定) >> よくなかったです（過去否定）
-
先週（せんしゅう）は忙しかった（いそがしかった）ですから、どこも行きませんでした（いきませんでした）。上週因為很忙，哪裡都沒去。
忙しい（いそがしい） >> 忙しかった
行く(いく。五段動詞. 原形) → 行きます(敬體肯定) → 行きません(敬體否定) → 行きませんでした(敬體否定過去)

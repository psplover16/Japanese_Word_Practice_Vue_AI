ch5. 助詞 は
A は B です
は發音 與 寫不同。へ也是發音與寫不同，表示方向。 為二例外。
は 不是主詞標記，而是主題標記，我現在要講的是 A 這件事，關於 A，它是 B。
は 前面「整個名詞塊」都是主題
--
主題 = 主語
妻（つま）は　お弁当（べんとう）を　 作り（つくり）ました
一. お弁当 お 是美化語（敬語前綴），讓詞聽起來比較禮貌、柔和，不是每個名詞都能加，屬於固定用法
二. を是受詞助詞（標示動作的對象）
三. ました ます形的過去式
--
主題≠主語
この弁当は　妻が作りました
--
主詞省略以下三種情況
👉 主題明顯
👉 語境清楚
👉 時間詞
一. 明日（あした）、何（なに）をしますか。 (時間詞，は省略)
二. 明日は、何をしますか。
明天(主題是明天)要做什麼？  主語省略，通常指你
三. あなたは 明日は、何をしますか。
那你明天要做什麼？  兩個主題，大主題是你，小主題是明天 (あなた是指 你)
四. 明日（あした）、あなたは何（なに）をしますか。
明天，你要做什麼？  重點落在「你」身上，而不是「明天」

富士山は日本でいちばん高い（たかい）山です。

いちばん + 形容詞
Aで いちばん + 形容詞 + 名詞     A是場所
いちばん + 動詞
ex.

ch6. 助詞 も與其他的助詞
も　助詞，表示也。
以下是其他助詞與 も 使用上的分類
一. 原本助詞必定消失，被 も 替換 (必省略)
    一-1.
        主題は，高橋さんは学生です。山田さんも学生です。
    一-2.
        焦點が，寿司が好きです。ラーメンも好き（すき）です。
        が，主語，或 跟狀態/感覺/能力 一起用，句子中間的 が 很常等於「但是、可是」，語氣比 でも 更柔和。 

二. 原本助詞幾乎會被替換 (極少部分不會被省略)
    動作作用對象を，新聞（しんぶん）を買いました（かいました）。 雑誌（ざっし）も買いました。
        1. 買う(詞幹) >> 買います(ます形) >> 買いました（過去敬語）
        2. を，表示"動作"的「對象」，名詞 + を + 動詞

三. 很常省略
    移動方向へ，京都（きょうと）へ行きました（いきました）。奈良（なら）へも　行きました。
        1. 行く(原形) >> 行きます(ます形) >> 行きました (過去形)
        2. 第二句的 へ，可省略，因為有 も

四. 不可省略
    四-1. 
        動作主題に，母に　プレゼント を あげました。父にもあげました。
            1. 我送給媽媽禮物，也送給爸爸禮物。
            2. プレゼント 表示禮物
            3. 此處的 に，表示接受動作的人
            3. を 受詞助詞，表示動作的對象。名詞都要用助詞標示語法腳色
            4. あげる >>> 一段動詞
                表示 誰給誰
                あげる 我給別人
                くれる 別人給我
                もらう 我收到で
            5. 私は父にもあげました。 此句私は 可以省略主語
                因為 あげる 具有方向性，可以清晰知道主語，所以主語可以省略
    四-2.
        交通工具で，電車（でんしゃ）で 行く（いく）こと が できます。バスでも行くことができます。
            1. 可以搭電車去，也可以搭巴士去。
            1. で 助詞，用 ~~手段 / 方法 
            3. 行く，表示 去。 こと 把動詞變成事情或動作的概念 (動詞變成名詞)
            4. が，主語標記。 行くこと 是主語
            5. できる ，一段動詞，表示 "能夠"。前面要接名詞。 
                但此處是用敬體的變化
                形式 意思
                できます 可以
                できません 不可以
                できました 可以了

ch9. 助詞：動作進行時点「に」  に其中一個用法，用於表示動作進行時間點。在A時候做B
A(時間名詞) に B(動作)  有動作才要加 に
沒動作不需要 ex.今（いま）、八時（はちじ）です.

不加に
相對的時間詞：　明日に病院へ行きます
不特定時間詞：　朝シャワーを浴びます　　　　昼（ひる）　夜（よる）夕方（ゆうがた）      浴びる（あびる，一段動詞）: 1. 水、光、陽光灑在身上 日光を浴びる 2. 抽象地「受到、遭受」注目を浴びる
最好要加に，口語才不加
曜日　　　　：　月曜日（げつようび）に 国（くに，名詞）へ(祝詞)帰ります（かえります，動詞）
要加に
絕對的時間詞：　7時（しちじ）に 起きます（おきます）  7點起床
不特定與絕對：　朝8時（はちじ）に 家（いえ）を 出ます（でます）
その他(ほか)：　クリスマスに 彼女（かのじょ）と 食事（しょくじ，名詞）します(動詞)    聖誕節和女朋友一起吃飯   
--
サ変動詞 食事します     就是把「名詞」接上 する，變成「做～、進行～」的動詞。 然後 禮貌形 します
--
木村（きむら）さんは毎晩（まいばん）何時（なんじ）に寝ます（ねます）か

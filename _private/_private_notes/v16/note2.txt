核心字詞使用方式

====================
1. い形容詞
====================

例詞：
- 高い
- 安い
- 早い
- おいしい

特徵：
- 詞尾本身是「い」。
- 本身就帶有「形容」功能。
- 但不是所有結尾是「い」的字都是 い形容詞，例如「きれい」就是 な形容詞。

A. 直接修飾名詞
格式：い形容詞 + 名詞

例：
- 高い山 = 高山
- 安い店 = 便宜的店
- おいしい料理 = 好吃的料理

B. 放句尾
說明：可以直接當述語，不需要接「だ」。

例：
- この山は高い。
- この料理はおいしい。

C. 否定
變化：把「い」改成「くない」

例：
- 高い → 高くない
- おいしい → おいしくない
- この山は高くない。
- この料理はおいしくない。

D. 過去
變化：把「い」改成「かった」

例：
- 高い → 高かった
- 安い → 安かった
- 昨日は安かった。
- その映画はおもしろかった。

E. 過去否定
變化：把「い」改成「くなかった」

例：
- 高い → 高くなかった
- おいしい → おいしくなかった


====================
2. な形容詞
====================

例詞：
- 静か
- 便利
- きれい
- 親切

特徵：
- 不像 い形容詞那樣能直接修飾名詞。
- 修飾名詞時要加「な」。

A. 直接修飾名詞
格式：な形容詞 + な + 名詞

例：
- 静かな部屋 = 安靜的房間
- 便利なアプリ = 方便的 App
- きれいな花 = 漂亮的花

B. 放句尾
說明：句尾通常接「だ」或「です」。

例：
- この部屋は静かだ。
- この町は便利です。

C. 否定
常見形式：
- 静かではない
- 静かじゃない

例：
- ここは便利じゃない。
- あの人は親切ではない。

D. 過去
常見形式：
- 静かだった
- 便利だった

例：
- 昔、この町は静かだった。
- そのホテルは便利だった。

E. 過去否定
常見形式：
- 静かではなかった
- 静かじゃなかった


====================
3. 名詞
====================

例詞：
- 学生
- 日本人
- 本
- 先生

特徵：
- 名詞主要用來表示人、事、物、概念。

A. 接名詞
說明：名詞不能直接修飾另一個名詞，通常要用「の」。

例：
- 日本の会社 = 日本的公司
- 学校の先生 = 學校的老師
- 台湾の料理 = 台灣料理

B. 放句尾
說明：句尾通常接「だ」或「です」。

例：
- 私は学生だ。
- 彼は先生です。

C. 否定
常見形式：
- 学生ではない
- 学生じゃない

例：
- 私は学生じゃない。
- あの人は日本人ではない。

D. 過去
常見形式：
- 学生だった
- 先生だった

例：
- 彼は昔、先生だった。

E. 過去否定
常見形式：
- 学生ではなかった
- 学生じゃなかった


====================
4. 動詞
====================

例詞：
- 行く
- 食べる
- 読む
- 来る

特徵：
- 動詞表示動作、變化、存在。

A. 放句尾
說明：動詞可以直接當述語。

例：
- 学校へ行く。
- ご飯を食べる。
- 本を読む。

B. 禮貌形
例：
- 行きます
- 食べます
- 読みます

C. 否定
普通形常見：
- 行かない
- 食べない
- 読まない

例：
- 今日は行かない。
- 肉は食べない。

D. 過去
常見形式：
- 行った
- 食べた
- 読んだ

例：
- 昨日学校へ行った。
- もうご飯を食べた。

E. 修飾名詞
說明：動詞用普通形直接修飾名詞。

例：
- 昨日買った本 = 昨天買的書
- 日本へ行く人 = 要去日本的人
- そこで働いている人 = 在那裡工作的人

這點很重要：
- 動詞修飾名詞時，不像な形容詞要加「な」。
- 動詞修飾名詞時，也不像名詞要加「の」。


====================
四類的核心差別
====================

先看「修飾名詞」：

- い形容詞：直接接
  例：高い山
- な形容詞：加「な」
  例：静かな部屋
- 名詞：加「の」
  例：日本の会社
- 動詞：用普通形直接接
  例：昨日買った本

再看「放句尾」：

- い形容詞：直接放
  例：高い
- な形容詞：接「だ / です」
  例：静かだ
- 名詞：接「だ / です」
  例：学生だ
- 動詞：直接放
  例：行く


====================
一張最實用的對照表
====================

類別       | 例子   | 修飾名詞     | 放句尾
-----------|--------|--------------|--------------
い形容詞   | 高い   | 高い山       | 山は高い
な形容詞   | 静か   | 静かな部屋   | 部屋は静かだ
名詞       | 日本   | 日本の会社   | ここは日本だ
動詞       | 買う   | 買った本     | 本を買う


====================
最後整理
====================

這四類最關鍵的差別是：

- い形容詞：自己就能形容。
- な形容詞：修飾名詞時要加「な」。
- 名詞：修飾另一個名詞時常加「の」。
- 動詞：用普通形直接修飾名詞，或放句尾表示動作。
